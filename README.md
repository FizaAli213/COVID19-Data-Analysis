# COVID-19 Data Analysis using PySpark

## Project Overview
This project analyzes COVID-19 data using PySpark and Jupyter Notebook.

## Tasks Performed
- Loaded CSV dataset
- Cleaned missing values
- Filtered Pakistan data
- Calculated total COVID cases and deaths
- Found countries with highest COVID cases
- Generated insights from dataset

## Tools Used
- Python
- PySpark
- Jupyter Notebook
